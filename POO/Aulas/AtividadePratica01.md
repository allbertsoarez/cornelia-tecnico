### 📝 Atividade Prática: Criando um Cartão de Visitas em Python

**Contexto:**
Você foi contratado como programador para desenvolver um pequeno sistema que gera cartões de visitas personalizados. O seu primeiro desafio é criar um programa em Python que, ao ser executado, exiba na tela um cartão com os seus dados.

### 🎯 Requisitos do Cartão

Ao executar o seu programa, o resultado na tela deve ser exatamente este (substituindo pelos seus dados):

```
=================================
Nome: (seu nome aqui)
Profissão: (sua profissão ou a profissão dos seus sonhos)
Frase: (uma frase motivacional que represente você)
=================================
```

**Regras obrigatórias:**

1. O cartão deve ter uma linha de cabeçalho e uma linha de rodapé feitas com caracteres especiais (como `=`, `*`, `-` ou `~`).
2. Devem aparecer 4 linhas de informação no meio do cartão (Nome, Profissão, Frase e mais uma à sua escolha).

---

### 📋 Critérios de Avaliação

Sua atividade será avaliada considerando:

| Critério                                               | Pontos |
| ------------------------------------------------------ | ------ |
| O código foi escrito do zero (sem copiar do colega)    | 1,0    |
| O programa foi executado sem erros                     | 2,0    |
| O cartão apareceu formatado corretamente na tela       | 2,0    |
| Foram usados comentários no código                     | 1,0    |
| Os dados foram personalizados (nome, profissão, frase) | 1,0    |
| TOTAL                                                  | 7,0    |

---

### 🌟 Desafio Bônus (+3,0 ponto)

Se você terminar antes do tempo e quiser ganhar um ponto extra:

- Adicione mais duas informações ao cartão (ex: e-mail, cidade, idade, hobby...).
- Crie um desenho em ASCII no topo ou no final do cartão (ex: um coração feito com caracteres, uma estrela, um emoji com símbolos).
