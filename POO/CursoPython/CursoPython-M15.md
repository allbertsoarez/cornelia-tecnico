### 15. Saindo do Navegador (O Mundo Local)
Neste módulo final, deixamos o Google Colab e configuramos o ambiente de desenvolvimento local (no próprio computador), preparando o aluno para criar aplicações desktop e scripts autônomos.

- **15.1 Instalação do Python Local**: 
  - Download da versão oficial em python.org.
  - A importância crítica de marcar a opção **"Add Python to PATH"** durante a instalação no Windows.
  - Verificação da instalação via terminal (`python --version`).

- **15.2 O Ambiente de Desenvolvimento (VS Code)**: 
  - Instalação do Visual Studio Code.
  - Instalação das extensões essenciais: **Python** (oficial da Microsoft) e **Pylance** (para inteligência de código e autocompletar).
  - Como selecionar o interpretador Python correto no VS Code.

- **15.3 O Terminal e a Execução de Scripts**: 
  - A diferença entre o ambiente interativo (REPL) e a execução de arquivos `.py`.
  - Como rodar um script pelo terminal (`python meu_script.py`).
  - O conceito de diretório de trabalho e caminhos relativos para salvar arquivos JSON localmente.

- **15.4 Interfaces Gráficas Desktop (Tkinter)**: 
  - O Tkinter é a biblioteca padrão do Python para criar janelas, botões e campos de texto nativos do sistema operacional.
  - O conceito de "Event Loop" (`mainloop()`): O programa fica em um loop infinito esperando o usuário clicar ou digitar.
  - Adaptação da arquitetura do Projeto Final (separando a Lógica de Negócios da Interface Gráfica).
